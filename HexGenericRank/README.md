# HexGenericRank

Generic rank of multivariate polynomial matrices, using HexRank's certificate
and HexMvGcd's exact division. `genericCert`, `genericRank`, and `genericCert?`
work over integer, rational, and prime residue coefficients without Mathlib.

See [the SPEC](SPEC/hex-generic-rank.md) and
[performance measurements](../reports/hex-generic-rank-performance.md).
