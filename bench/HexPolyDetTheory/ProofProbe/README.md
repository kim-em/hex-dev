# Symbolic determinant examples

CI builds numeric, symbolic and quotient equalities, numeric and symbolic result
production, and the original quadratic 4×4 and rank-one 10×10 regressions through
`HexPolyDetTheoryProofProbe`. The broader frontend regression corpus remains in
`HexPolyDetTheory/Tests.lean`. Larger focused correctness cases live under
`conformance/HexPolyDetTheory/Diagnostics`; build them with
`lake build HexPolyDetTheoryDiagnostics`.
