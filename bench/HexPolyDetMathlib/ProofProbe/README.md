# Symbolic determinant examples

CI builds numeric, symbolic and quotient equalities, numeric and symbolic result
production, and the original quadratic 4×4 and rank-one 10×10 regressions through
`HexPolyDetMathlibProofProbe`. The broader frontend regression corpus remains in
`HexPolyDetMathlib/Tests.lean`. Larger focused correctness cases live under
`conformance/HexPolyDetMathlib/Diagnostics`; build them with
`lake build HexPolyDetMathlibDiagnostics`.
