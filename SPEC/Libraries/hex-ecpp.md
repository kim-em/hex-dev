# ECPP library pair

The active specifications are [hex-ecpp](../../HexECPP/SPEC/hex-ecpp.md)
for the Mathlib-free checker and [hex-ecpp-theory](../../HexECPPTheory/SPEC/hex-ecpp-theory.md)
for the Hasse proof, group-law correspondence, primality soundness, and
explicit elaborator. The dependency versions are recorded in
`lake-manifest.json`.
