# hex-lll-mathlib

Part of [`hex`](https://github.com/kim-em/hex-dev), a computer algebra library
for Lean 4. The aim is fast executable code, fully verified, built with
spec-driven development.

`hex-lll-mathlib` relates the executable integer lattice operations from
[`hex-lll`](https://github.com/leanprover/hex-lll) to Mathlib submodules and
Euclidean norms, building on
[`hex-gram-schmidt-mathlib`](https://github.com/leanprover/hex-gram-schmidt-mathlib)
and [`hex-row-reduce-mathlib`](https://github.com/leanprover/hex-row-reduce-mathlib).
Its principal theorem says that the first row returned by `Hex.lll` is short
relative to every nonzero vector of the input lattice.

# Quickstart

```toml
[[require]]
name = "hex-lll-mathlib"
git = "https://github.com/leanprover/hex-lll-mathlib.git"
rev = "main"
```

```lean
import HexLLLMathlib

open HexLLLMathlib

#check @lll_first_row_norm_sq_le
#check @lllNative_first_row_norm_sq_le
#check @latticeSubmodule
#check @lll_mem_latticeSubmodule_iff
#check @norm_sq_intRowToEuclidean
```

# Functionality

- `latticeSubmodule` is the `ℤ`-submodule generated by the executable matrix
  rows; `mem_latticeSubmodule_iff` characterizes it by
  `Hex.Matrix.memLattice`.
- `intRowToEuclidean` and `intVectorToEuclidean` embed integer coordinates in
  `EuclideanSpace ℝ (Fin m)`, with squared-norm characterization theorems.
- `lll_mem_latticeSubmodule_iff` and its native counterpart prove that
  reduction preserves the generated submodule.
- `lllReduced_sound`, `lllReducedInterval_sound`, `lllReducedCheck_sound`, and
  `certCheck_sound` prove soundness of the executable checkers.

# Verification

For an independent basis and `121/400 < δ ≤ 1`,
`lll_first_row_norm_sq_le` bounds the squared norm of the first reduced row by

```text
(1 / (δ - 121/400))^(n - 1)
```

times the squared norm of any nonzero lattice vector. The corresponding
theorem for `lllNative` uses the tighter classical denominator `δ - 1/4`.
The lattice-preservation theorems state that both returned bases generate
exactly the input submodule.

See the [SPEC](SPEC/hex-lll-mathlib.md) for the theorem map and precise
hypotheses.
