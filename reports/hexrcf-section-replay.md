# Frozen selected sections and source quotation

`SectionReplay.check` validates a supplied selected-root descriptor, its graph
and a complete ordered joint row through the existing owner readers. Original
divisors are checked before parsing. Accepted true yields one ordinary real
witness; accepted false yields one point counterexample. `check_fields` retains
the full decoded subject and row, and `check_domains` proves the supplied
divisors nonzero under the actual predecessor model.

`checkWith` uses the owner's eight equal supplied coefficient operations both
to reconstruct the context and to check its row. `checkWith_eq` preserves every
true, false and rejected result. `ScalarPacket.read` independently checks a
supplied polynomial/sign/graph packet. `fields` authenticates its literal key
and sign; `restore` reuses checked acceptance for subsequent scalar lookup.
Its key parser's default is unreachable after successful packet acceptance.

`SectionBuild.build` uses the native family and BKR producer to find a true
selected section. Its output contains literal descriptor, graph and row data,
plus untrusted hints for every predecessor coefficient stored in both graphs
and the row. Zeros and duplicates remain in this traversal. A strict codec
requires seed facts before it can restore those literals; a missing literal
does not itself emit an arithmetic request. Subsequent reached operations may
require additional scalar packets. All proposed packets still require kernel
replay. Search errors retain the owner's actual `BuildError`.

`SectionQuote.finish` reifies the original target again, checks the exact
existential matrix, fixed coefficient valuation and ordered original divisor
identities, and transports the witness through the actual source equivalence.
Every proof, including the final original target, passes the ordinary kernel
and complete axiom screening. Failure restores the saved environment/state.

The source conformance reifies the positive √2 coefficient example, produces
new section/row evidence for its actual matrix and quotes the original goal.
The reifier's lower-bound polynomial is `1-x`, so the old hand-written row's
`x-1` key cannot substitute for it. The parent, selected √2 coordinate and real
interpretation use the existing checked fixture. Production uses no old
row-truth theorem. Seed facts are checked from the produced literal hints;
the reached-fact collector checks later requests. Packed values look up
the reduced polynomial, so the supplier records that exact reduced key rather
than the unreduced missing-operation input. Repeated reduced requests are
rejected after checked supply. Seed lists are stored as checked shared
declarations; scalar acceptance uses the existing single guarded kernel
decision pattern. Fresh section acceptance uses the same native-production
diagnostic guard as the frozen fixture.

The frozen conformance checks malformed subject, graph and row data, a zero
original divisor before malformed packets, a false point row and a changed
coefficient with unchanged evidence. Source refusals cover a universal target
and omitted cancelled-zero divisor identity, with unchanged environment after
failure. A separate compilation unit quotes the source proof again and checks
that its local proof closure contains section/scalar replay laws and no
producer. These concrete fixtures use ordinary non-module imports in the
pinned toolchain. The generic adapter modules use public module imports.

The producer currently visits selected roots. Point roots and sectors remain
outside its search, and `none` means no supported witness was found; it never
certifies a false existential sentence. The model and source coordinates still
need prior authentication. The source probe is deliberately restricted to its
one authenticated algebraic coefficient and no original divisions. No new
`rcf` handler is registered, and this tranche does not provide generic source
coefficient discovery or accepted algebraic search completeness.
