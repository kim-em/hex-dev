# Frozen selected sections and source quotation

`SectionReplay.check` validates a supplied selected-root descriptor, its graph
and a complete ordered joint row through the existing owner readers. Original
divisors are checked before parsing. Accepted true yields one ordinary real
witness; accepted false yields one point counterexample. `check_fields` retains
the full decoded subject and row, and `check_domains` proves the supplied
divisors nonzero under the actual predecessor model.

`checkWith` uses the owner's eight equal supplied coefficient operations both
to reconstruct the context and to check its row. `checkWith_eq` preserves every
true, false and rejected result. `ScalarPacket.read` independently checks a
supplied polynomial/sign/graph packet. `fields` authenticates its literal key
and sign; `restore` reuses checked acceptance for subsequent scalar lookup.
Its key parser's default is unreachable after successful packet acceptance.

`SectionBuild.build` uses the native family and BKR producer to find a true
selected section. Its output contains literal descriptor, graph and row data,
plus untrusted hints for every predecessor coefficient stored in both graphs
and the row. Zeros and duplicates remain in this traversal. A strict codec
requires seed facts before it can restore those literals; a missing literal
does not itself emit an arithmetic request. Subsequent reached operations may
require additional scalar packets. All proposed packets still require kernel
replay. Search errors retain the owner's actual `BuildError`.

`SectionQuote.finish` reifies the original target again, checks the exact
existential matrix, fixed coefficient valuation and ordered original divisor
identities, and transports the witness through the actual source equivalence.
Every proof, including the final original target, passes the ordinary kernel
and complete axiom screening. Failure restores the saved environment/state.
