# Automatic algebraic goals through finite replay

The optional `HexRCF.RealCoefficients` import enables ordinary `by rcf` on the mixed selected-quartic/√2 goals in [FiniteDefault](../conformance/HexRCF/FiniteDefault.lean). Let α be the specified selected real root of X⁴+4X³−X²−7X−2. The tactic proves positivity of x²+α+√2, the implication `(x−α)(x−√2)<0 → 1<x∧x<2`, and positivity of x²+√(α+√2). These exercise independently constructed coefficient fields, root sections/sectors and a nested algebraic coefficient.

Native production uses the actual checked number field. Accepted finite proofs use ring-preserving transport, checked signs, nonzero leading coefficients, complete root/cell evidence and exact source identities. They quote no new irreducibility certificate for the combined degree-eight or nested degree-sixteen presentation. Original input constructors retain their own certificates. The [finite interface](../adapters/HexRCF/RealCoefficients/FiniteLiteral.lean) reuses the existing producer, shared formula syntax and cell laws.

[Guarded compilation](../adapters/HexRCF/RealCoefficients/FieldCompile.lean) checks each proposed quotient by a frozen multiplication identity and a proof that its original denominator is nonzero. Original divisors survive cancellation, zero multiplication and empty domains. A per-preparation memo shares nonvanishing proofs for equal native coordinates; different quoted forms require an ordinary-kernel coordinate equality. The final cell table need not repeat independently checked original-divisor signs. Three reads in two forms invoke the test sign producer once, while a fresh preparation rechecks it. This callback-count regression is not a timing measurement or all-distinct-denominator batching. [Coordinates](../adapters/HexRCF/RealCoefficients/Preparation.lean) separates authenticated source data from legacy Environment's global irreducibility proof; existing editable Environment APIs retain independent validation. Nested root proposals reuse the existing owner root algorithm over the known base field; selected equations/enclosures still authenticate their interpretation.

[FiniteIndex](../adapters/HexRCF/RealCoefficients/FiniteIndex.lean) proves equal Boolean acceptance for linear and indexed retrieval for every supplied packet. Malformed routes, degenerate comparators, missing/corrupt signs and swapped contexts are covered. Indexing does not omit retained repeated rows or imply shared validation of repeated arithmetic evidence.

[Fresh ordinary-import audits](../conformance/HexRCF/FiniteDefaultProofs.lean) recheck ten actual exported/retained bodies for five default/nested source proofs and follow 19,692 project declarations. Their complete axiom closures are exactly propext, Classical.choice and Quot.sound. Producer/global inverse/zero-reflection dependencies and new common degree-eight/degree-sixteen class quotation are excluded. Each root is inspected independently for every actual closed presentation: seventeen presentations across the five roots, with the intended degrees required. A separate explicit legacy proof supplies a positive control that the same audit detects the common-field class. Cached arithmetic auxiliaries were checked when emitted; the composition rechecks do not recompute those auxiliaries. The class-provider scan explicitly covers literal/reducible aliases and closed named providers, not arbitrary opaque equivalences or bound provider applications. The public finite quotation entry point restores state on failure and forces ordinary kernel checking. Both single-Boolean and split-conjunct replay modes use the same envelope; the comparison option is exercised on the finite route.

The root/maximal-coefficient audits require the actual finite-cell soundness laws. The explicit multi-prime irreducibility API retains a separate kernel-checked certificate regression. The common-octic goal has an unconditional tactic proof. Default controls retain rational and fourth-root success; false, deliberately exhausted and cancelled-zero-divisor calls leave the original goal unassigned and no temporary declarations.

## Scope

This is automatic finite algebraic integration, not full #10358 completion. Public `Coefficients.prepare` authenticates source coordinates; their `build` and frozen `check` methods expose the finite route. `prepareCoordinates` retains that operation, while explicit `prepareField` returns the legacy Environment. The finite Boolean replay API checks source bindings and every original divisor and preserves accepted false as a diagnostic. Complete source construction and all-resource bounded progress, general-context/registered-constant/realization integration and remaining evidence/conformance stay open. Finite certified successes require neither convergence nor transcendence. Conditional total named towers still require the appropriate shrinking and relative-transcendence laws, and symbolic infinitesimals are never used as real witnesses.

The [direct frontend regression](../conformance/HexRCF/FrozenReplay.lean) prepares a guarded quartic/√2 source, builds its bound certificate and checks an original-goal proof. It tests changed coefficients/quantifiers, missing divisor signs and missing atom rows, and builds accepted false certificates with generator refinement both disabled and enabled. The explicit complete producer also constructs true and false certificates for this source, with ordinary-kernel acceptance of its original goal. Quotation refuses false and malformed evidence without retaining temporary declarations. A [fresh ordinary-import audit](../conformance/HexRCF/FrozenReplayProofs.lean) rechecks ten replay/cell laws and definitions, nineteen production laws/definitions and four actual source proof bodies. Six concrete presentations are inspected; each source proof requires the degree-eight presentation while excluding its new irreducibility class and all numerical producers. These checks add no matched performance result to the source-pinned lookup study above.

The [complete grouped producer](../adapters/HexRCF/RealCoefficients/FieldCellProgress.lean) reuses the existing normalized radical, selected-field isolation, atom-row and literal-sign builders. Its direct-depth default is 256, matching the tactic option. It derives the strict retained row inventory, finite leading guards and complete sign coverage from their actual construction. `Replay.buildCellsTotal_spec` proves every valid prepared input yields a correct accepted true or false result. `Coordinates.buildTotal` exposes that construction without changing bounded tactic defaults; `Coordinates.check` performs the same frozen acceptance and source transport afterward. The [native controls](../conformance/HexRCF/FiniteProduction.lean) execute depth-zero construction of `x²=√2` with `1<x<2`, repeated atom occurrences and original divisors, both quantified verdicts, reordered-guard rejection, empty formulas and missing-evidence refusals. This is prepared-input algebraic completeness, not a theorem of complete source recognition or registered-constant search.

The [common-field construction laws](../adapters/HexRCF/RealCoefficients/CommonSource.lean) prove that the actual generator stays real for real algebraic inputs and that its coordinates retain their original real values. The proof covers zero inputs, the two-input shortcut and the general primitive-element construction. These are producer laws, separate from frozen source replay; quoted source proofs still exclude `QAdjoin.common`. Bounded and complete production use the same grouped polynomials and complete operand inventory. All-resource completeness of the bounded isolation schedule remains a separate obligation.

`CommonPresentation.build_complete` proves that the actual sign-table builder supplies an accepted presentation when its coordinates satisfy the source equations and strict selected-root margins. It assumes neither an accepted certificate nor successful sign lookup. Deriving those source conditions and a printable root header remains part of complete source construction.
