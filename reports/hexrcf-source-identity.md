# Packet-derived selected-source identity

`SourceIdentity.quoteWith` independently quotes the source equation and
isolating-square margin, then proves that their selected root equals the
original real coefficient. Both facts must belong to the same context: the
equation has sign zero and the margin has sign positive. Checked polynomial
value laws bind both packet keys to the original source. A source equation
alone cannot distinguish real conjugates.

The generic helper retains the caller's prepared-context equality, ordinary
real model, anchor selection and coefficient value laws. It performs no root
or sign search. Its enclosing `RootQuote.runWith` supplies the shared budget
and transaction. No solver handler, field instance or owner proof is added.

The frozen positive-square-root regression uses 673,461 proof nodes. A valid
negative-window packet is independently accepted with sign −1, but cannot
identify the positive native root with the negative selected conjugate.
Wrong coefficient proofs and one-node-below limits also fail with complete
metavariable and auxiliary-declaration restoration.

The resulting coefficient identity replaces the handwritten identity in the
complete source proof of
`∃ x : ℝ, x²−Real.sqrt 2 ≥ 0 ∧ x²−Real.sqrt 2 ≤ 0 ∧ 0=0`.
The cell reification/quotation still charges 8,644,422 nodes before separate
source finishing. This is a fixed-parent example with supplied seed facts,
not arbitrary predecessor-history reconstruction.
