# Frozen selected-root context transport

`RootTransport.read` restores a supplied target descriptor and checks its full
raw identity against the actual coefficient conversion of the source root.
Supplied source divisors are checked before any subject or graph parsing.
Zero divisors, invalid evidence and valid-but-different subjects have separate
`divisor`, `evidence` and `binding` outcomes. No message matching or solver
fallback is used. The accepted result is indexed by the exact guard list and
retains each nonzero proof. Source-to-guard-list authentication remains the frontend
caller’s obligation; this reader does not reconstruct a source goal.

`readWith` accepts equal supplied coefficient maps and five arithmetic operation
dictionaries. The owner's `Descriptor.changeOps` retains the literal descriptor
and evidence with canonical proof indices. `readWith_eq` preserves every
canonical result/error. `read_fields` and `read_subject` retain the owner's
accepted reader and complete decoded fields; `Checked.domains` proves every
retained divisor is nonzero in the source interpretation.

The converted descriptor assembles an actual `Transport.adjoin` conversion
through `step`. Its `model` uses `Conversion.Model.adjoinWith` to preserve every
old-context value at the same selected root, without a native validation-success
hypothesis. Later scalar packing is the native owner's closure and still needs
its own finite checked assembly when used during kernel quotation. This is not
an automatic arbitrary-history or all-live quotation implementation.

The fixed-parent regression moves the checked positive root of X²−2 into the
already authenticated positive-√2 context. Its coefficient map is literally
proved equal to the owner's actual predecessor inclusion. Three constant-sign
records follow from `Context.signPoly_const`; no pre-supplied row facts are
used. Guarded acceptance forbids native root/scalar production, native polynomial
packing, descriptor validation and native per-descriptor production. Cached
packing from supplied checked records and literal graph parsing remain allowed.
A valid negative-root certificate rejects specifically with `binding`; it is not merely malformed
evidence. Missing finite records yield `evidence`. The stale-context control changes
only the parent-encoded subject’s signature, independently checks successful
coefficient/subject parsing and successful graph parsing with its original
signature, head and endpoints. The owner’s literal context comparison rejects
the changed subject before replay.
A zero divisor wins over malformed subject and graph data.

Actual owner root uniqueness proves that the converted root denotes √2, while
the assembled model uses the owner’s value-preservation law. A fresh ordinary
consumer checks the exact root identity and a direct use of that law.
Complete axiom inventories allow only propext, Classical.choice and Quot.sound.
Local body scans treat imported declarations as leaves. Frozen literals share
constructor subtrees and are regenerated without a producer.

No complete root/cell coverage, arbitrary source/provider history, accepted
algebraic completeness or performance gain is claimed. The optional adapter
keeps the existing [generator-window](https://github.com/kim-em/hex-dev/issues/10633)
and [reduced-coordinate](https://github.com/kim-em/hex-dev/issues/10634) interfaces
and their retained measurement limits.

The target context retains the supplied descriptor’s evidence, including the
frame encoded from it. Equivalent selected roots with different evidence do
not imply literal context identity. `step_native` agrees with the owner’s
`adjoinChecked` only when it returns this exact descriptor; frozen acceptance
does not rely on that native-production premise. This adapter assembles the
existing `Conversion.ofTransport` and `Transport.adjoin` constructors and
consumes the existing model law; it adds no arithmetic or root-search algorithm.

`Checked.domains` proves the retained source guards are nonzero under their
original interpretation. `Checked.transported` consumes the owner’s actual
`Conversion.Model.zero` and proves the converted guards remain nonzero. The
frontend still authenticates the retained list against the source goal.

The original fixture accepts nonempty guards `[2, -1]`. A separately valid
positive-root descriptor with an added derivative word uses one further
proved constant-sign record for 4; the requested source binding rejects
it despite the same polynomial, endpoints and selected real root. Generic
`read_zero`, `read_evidence` and `read_binding` state the distinct outcomes.
The fresh consumer re-derives root preservation with `Conversion.Model.root`
and value preservation with `adjoinWith`, passes both theorem bodies to the
ordinary kernel, scans their local bodies
for the actual owner laws, and requires exactly the standard three axioms.
Imported declarations are leaves in those scans; native producer exclusion
comes from the active acceptance/refusal kernel diagnostics, not from looking
inside imported data.

The validation records bind exact source/dependency hashes to successful
ordinary Lake builds of the optional adapter, transport regressions, fresh
consumer, full manual and complete manual render. Compressed logs retain their
decoded hashes. Desktop and narrow captures retain the external render driver
and inspection data; the new example fits its narrow code area. Source-distinct
records are kept separately. These are validation results, not a runtime or
scaling experiment. Existing manual examples and the base rational interface
remain in the same build.
