# Joint realization of the original nested tower fixture

`GuardJointPublic.exists_points` provides one base interpretation and two
ordinary real coordinates for the original selected extension `X − (ε + δ)`
and the positive selected root of `Y² − α`. Its full proposition retains the
ordered coefficient agreement, inherited provider values, both original
packing/sign/inverse inventories, all 3773 original guards, and the native
product together. These are 3778 clauses at the same readers and coordinates.
The outer witnesses contain the interpretation and two real points; they are
not three algebraic roots.

[`GuardJointUse.coordinates`](../experiments/KernelReplay/GuardJointUse.lean)
is an ordinary `module` consumer. It extracts the actual witnesses and derives
both original raw defining-polynomial equations and the computed native square
equation at those coordinates. The coefficient bound and coefficient identity
come from the independent finite operand reconstruction. The full dependency
audit below must establish independence from the older `FrameOperand` cached
operand and its whole-field reference construction.

[`GuardJointExport`](../experiments/KernelReplay/GuardJointExport.lean) uses
checked public names for the original native contexts and finite readers. It
shares nested proof arguments as ordinary checked theorem constants at the
propositions expected by their constructors. Inferring a cached proof's type can
instead retain `Bool.Reflects`, whose conversion to the expected proposition may
need private computational bodies. The exported theorem is kernel checked
against the complete original joint theorem; no clause or hypothesis is dropped.
The exported proposition remains transparent to an ordinary importing module.

The independent NONMODULE
[`GuardJointPublicAudit`](../experiments/KernelReplay/GuardJointPublicAudit.lean)
compares every guard clause directly with the original discovery template at
the shared readers, independently of the rewritten guard-theorem types. It also
traverses the actual
checked private and opaque bodies of the theorem, statement and consumer.
The permitted axiom closure is exactly `propext`, `Classical.choice` and
`Quot.sound`. The audit rejects transitive uses of
`BaseContext.PackedContext.Realization.reference`, `Ambient.ofField`,
`Ambient.exists_ambient` and `TauCeti.RealClosure.exists_realClosure`.
It rejects declarations originating in `KernelReplay.FrameOperand`, including
nested, macro-scoped and private generated names. The parametric
constant-polynomial constructor and its proof auxiliaries are allowed. Small controls reject the
old conditional product theorem, a theorem whose cached dependency appears only
in its proof body, and actual private scalar records. A positive control checks
the generic constructor. The full fixture additionally rejects original scalar
field-binding theorems through that same module boundary. The statement audit checks the complete
ordered base agreement, inherited providers, both inventories, every original
guard and the original native product. Its chosen-term absence check examines
direct occurrences in the advertised predicate.

Reproduce the full local correctness check from the repository root:

```sh
LEAN_NUM_THREADS=2 lake build KernelReplay.GuardJointPublicAudit
```

Validation uses an aggregate 8 GiB memory limit, no swap and two Lean threads,
with unchanged heartbeat limits. Acceptance requires all local Lean and build
configuration inputs to remain fixed and independently rechecks the 1240 frozen
original inputs. The evidence must bind the checked source files, compiler
artifacts, actual external compiler inputs and complete build log.
The linked [evidence manifest](real-closure-joint-replay/evidence.json) covers
its listed interface pins; those pins do not cover the module-ownership
exclusion and controls described above. Acceptance of those checks requires a
completed full audit and a matching archive. The archived `verify.py` is the
exact host-local archival verifier and needs the recorded external worktrees
and artifact archives. The Lean command above reproduces the mathematical
checks from this repository; the host-local archive verifier is a separate
provenance check.

The complete original fixture is a local validation target. The existing CI job
compiles shared finite/staged reconstruction helpers and the public arithmetic

using the existing public-frame dependencies. Its source-only admission scan
discovers every Lean module beneath an `experiments/KernelReplay/Guard*` file
or directory and checks its import cone; root discovery and source-shadowing
checks have their own regression. The complete 3773-guard fixture is compiled
locally. No CI job or workflow is added. The fixed counts identify this exact input, rather than production API
limits.

The public full-signature equations `Tower.Signature.codec_encode` and
`codec_literal` expose the existing encoding identity and lawful literal
roundtrip. `SignatureCodecTests` uses an ordinary import to identify a frozen
packet and decode arbitrary supplied full signatures. The owner equations and
three consumer proofs have exact axiom guards within the standard-three set.
These equations concern structured identity decoding; root and context
validation remain separate.

This is a fixed two-level fixture over two successive infinitesimals. It does
not complete the recursive exporter for arbitrary interleaved live collections,
general `Sample.realizeReplay`, strict compiled missing-inventory rejection or
the required Phase-4 tower measurements. Original π/e workloads remain
unsupported without their specified caller providers; no substitute prefix is
counted as the original workload. Issue #10378 remains open for its full scope.
