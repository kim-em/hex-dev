# Joint realization of the original nested tower fixture

`GuardJointPublic.exists_points` provides one base interpretation and two
ordinary real coordinates for the original selected extension `X − (ε + δ)`
and the positive selected root of `Y² − α`. Its full proposition retains the
ordered coefficient agreement, inherited provider values, both original
packing/sign/inverse inventories, all 3773 original guards, and the native
product together. These are 3778 clauses at the same readers and coordinates.
The outer witnesses contain the interpretation and two real points; they are
not three algebraic roots.

[`GuardJointUse.coordinates`](../experiments/KernelReplay/GuardJointUse.lean)
is an ordinary `module` consumer. It extracts the actual witnesses and derives
both original raw defining-polynomial equations and the computed native square
equation at those coordinates. The coefficient bound and coefficient identity
come from the independent finite operand reconstruction. The accepted consumer
does not depend on the older `FrameOperand` cached operand or its whole-field
reference construction.

[`GuardJointExport`](../experiments/KernelReplay/GuardJointExport.lean) uses
checked public names for the original native contexts and finite readers. It
shares nested proof arguments as ordinary checked theorem constants at the
propositions expected by their constructors. Inferring a cached proof's type can
instead retain `Bool.Reflects`, whose conversion to the expected proposition may
need private computational bodies. The exported theorem is kernel checked
against the complete original joint theorem; no clause or hypothesis is dropped.
The exported proposition remains transparent to an ordinary importing module.

The independent NONMODULE
[`GuardJointPublicAudit`](../experiments/KernelReplay/GuardJointPublicAudit.lean)
checks all original clauses at the shared readers and traverses the actual
checked private and opaque bodies of the theorem, statement and consumer.
The permitted axiom closure is exactly `propext`, `Classical.choice` and
`Quot.sound`. The audit rejects transitive uses of
`BaseContext.PackedContext.Realization.reference`, `Ambient.ofField`,
`Ambient.exists_ambient` and `TauCeti.RealClosure.exists_realClosure`.
It checks the complete ordered base agreement, inherited providers, both
inventories, every original guard and the original native product, and rejects
chosen implementation witnesses in the advertised predicate.

Reproduce the full local correctness check from the repository root:

```sh
LEAN_NUM_THREADS=2 lake build KernelReplay.GuardJointPublicAudit
```

The retained validation used an aggregate 8 GiB memory limit, no swap and two
Lean threads, with unchanged heartbeat limits. It verifies all local Lean and
build configuration inputs remained fixed and independently rechecks the 1240
frozen original inputs. The evidence record binds the checked source files,
compiler artifacts, actual external compiler inputs and complete build log.
See [the evidence manifest](real-closure-joint-replay/evidence.json).

This full original fixture is locally validated. The existing CI job builds
representative smaller finite/staged replay examples and the public arithmetic
helper; it does not build this complete 3773-guard fixture. The existing CI job
is extended without introducing another job or workflow.

This is a fixed two-level fixture over two successive infinitesimals. It does
not complete the recursive exporter for arbitrary interleaved live collections,
general `Sample.realizeReplay`, strict compiled missing-inventory rejection or
the required Phase-4 tower measurements. Original π/e workloads remain
unsupported without their specified caller providers; no substitute prefix is
counted as the original workload. Issue #10378 remains open for its full scope.
