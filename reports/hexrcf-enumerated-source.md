# Enumerated selected-source packets

`SourceBuild.build` enumerates roots through the existing `RootBuild.build`, then visits every candidate. `SourceBuild.select` requires a zero proposed equation sign and exactly one positive enclosure match. An ambiguous window, absent match, failed production or wrong equation returns a structured error. It retains the original polynomial and enclosure subjects and does not dispatch another solver.

`ScalarPacket.buildParts` exposes the existing producer's literal polynomial, integer sign and graph as an untrusted proposal. `Proposal.packet` preserves the three-field scalar layout. The existing `build` remains a wrapper with the same return type. These proposed integers and their data equalities are not evidence about real values; frozen replay and ordinary-kernel source identification establish that meaning.

The producer is registered in the existing optional adapter target and umbrella. The base umbrella stays independent. This is source certificate assembly, not a new arithmetic implementation, formula language, coefficient field or tactic handler.

The generic `ScalarPacket.buildParts_success` and `build_success` theorems derive actual packet production from the owner's `Descriptor.buildSigns_success` under a lawful ordinary-real parent model. They assume no successful table or producer output and have only the standard three axioms. They establish proposal production, not frozen replay acceptance for an arbitrary supplied codec. The lemmas live beside the producer definitions, preserving their hidden bodies and the existing replay implementation.
