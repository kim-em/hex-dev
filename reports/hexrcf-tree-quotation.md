# Public tree replay quotation

`RootQuote` now rewrites supplied replay trees through the owner's public
`Replay.check.eq_1` and `eq_2` equations before opening local node checks. This
keeps the replay function explicit during checked conversion. It does not add
an arithmetic operation, certificate producer, solver handler or field instance.

A complete-cell diagnostic exposed an expensive conversion from
`decide (Replay.check ... = true)` to a local node equation. A debug snapshot
retained the already checked prefix and stored the pending target and candidate
as expression data, without installing an unchecked theorem. Correct-candidate,
local-variable closure and wrong-goal rejection controls validated that debug
boundary. The exact captured target subsequently passed ordinary-kernel checking
with the public leaf equation, explicit Boolean transport and a Boolean
placeholder for the local check. The original and intermediate interrupted
attempts are retained; they are not completed performance comparisons.

## Complete-packet limit

The new full original-source experiment advances beyond the previous stalled
conversion but still exhausts its explicit five-million-node budget at
5,000,000 consumed plus one requested. It takes 38m13.237s and peaks at 4.3G as
reported by the bounded runner, with no swap. Original-source finishing and the
prepared importing source audit are not reached. The original polynomial,
shared matrix, supplied cells and frozen reduction are retained; no old
complete-fixture acceptance is counted as a fresh literal proof.

This is a targeted quotation experiment, not a scaling run, compiled family
benchmark or AB/BA speed comparison. The interrupted kernel diagnostics and
completed bounded refusal have different scopes and resource allowances.
Proof-node accounting and compiled module sizes do not establish physical DAG
sharing or serialized-certificate sizes. No speedup ratio is claimed.
