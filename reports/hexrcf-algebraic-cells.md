# Supplied cells over a fixed algebraic parent

The optional RCF adapter consumes a complete frozen cell certificate over
ℚ(√2), with the positive selected real embedding of the coefficient. It proves
an original real existential by fresh schema preparation, supplied scalar
replay, root/section/sector checking, radical identities and quotation.
This is finite acceptance for a fixed lawful ordinary-real parent. General
provider history, all-live changes of representation, automatic common-field
certification, algebraic construction completeness and strict compiled
checking with arbitrary missing predecessor records remain separate gates.

## Shared readers and coefficient operations

[RowOperations](../adapters/HexRCF/RealCoefficients/RowOperations.lean) supplies
the operation-parametric whole-row reader. Its transports retain the actual
root subject, query order, values and evidence. The canonical
[RowReplay](../adapters/HexRCF/RealCoefficients/RowReplay.lean) delegates to this
reader after original divisor preflight.

[CellPackets](../adapters/HexRCF/RealCoefficients/CellPackets.lean) stores a
checked point row, adjacent-root bounds and their same-point sector packet
with coefficient operations explicit in the types.
[CellPacketTransport](../adapters/HexRCF/RealCoefficients/CellPacketTransport.lean)
changes equal operations and query/root indices while preserving stored data.
[CellPacketConvert](../adapters/HexRCF/RealCoefficients/CellPacketConvert.lean)
connects these records to the existing canonical semantic interfaces.

[CellPacketRead](../adapters/HexRCF/RealCoefficients/CellPacketRead.lean) is the
shared six-field sector parser. It checks literal endpoint presence, strict
boundary signs, the linear descriptor for the requested point, and the whole
ordered row. The canonical
[SectorReplay](../adapters/HexRCF/RealCoefficients/SectorReplay.lean) retains
its public result type and delegates to this parser. Its original guard
preflight precedes specialization. There is one parser for each literal
format, no new formula syntax or owner arithmetic algorithm, and no field
instance on raw stored expressions.

The supplied operations are equal to the canonical operations by actual owner
laws. They allow ordinary-kernel replay to use frozen scalar facts. This is
not a strict general compiled checker: the owner's missing-record arithmetic
boundary retains its documented native compiled fallback. The literal value
codec itself rejects absent input records. No fallback is used as evidence for
the accepted kernel proofs.

## Complete algebraic matrix

The [fixture](../conformance-fixtures/HexRCF/cell-algebraic.json) contains a
full root table, two section rows and three sector packets for
p(X) = X²−√2. The source matrix is p(x) ≥ 0 ∧ p(x) ≤ 0 ∧ 0 = 0.
Its nonzero-atom product is p². Checked radical identities relate that product
to the root table's squarefree head p.

| Cell | Sample | Sign of p | Matrix |
| --- | --- | --- | --- |
| Left sector | −2 | positive | false |
| Negative root | −√√2 | zero | true |
| Middle sector | 0 | negative | false |
| Positive root | √√2 | zero | true |
| Right sector | 2 | positive | false |

[Records](../conformance/HexRCF/CellReplay/Algebraic/Records.lean) checks 21
frozen scalar packets from an empty inventory. Every polynomial, claimed sign
and graph comes from generated constructor data for the
[scalar fixture](../conformance-fixtures/HexRCF/cell-algebraic-scalars.json).
No supplier is called during acceptance.
[Read](../conformance/HexRCF/CellReplay/Algebraic/Read.lean) checks the complete
matrix with those operations.
[Convert](../conformance/HexRCF/CellReplay/Algebraic/Convert.lean) abstracts
over checked data before specializing the transports to the concrete decoded
packet; generic transport checking therefore does not force decoder reduction.
[Radical](../conformance/HexRCF/CellReplay/Algebraic/Radical.lean) verifies the
actual polynomial identities.
[Check](../conformance/HexRCF/CellReplay/Algebraic/Check.lean) checks the strict
existential true and universal false folds. Accepted false remains diagnostic.

[Meaning](../conformance/HexRCF/CellReplay/Algebraic/Meaning.lean) obtains the
exact real root set x² = √2 from the owner's complete supplied-table coverage.
It identifies both ±√√2 as members and obtains strict order from the accepted
table. It does not reuse an earlier existential witness.
[Quote](../conformance/HexRCF/CellReplay/Algebraic/Quote.lean) authenticates the
fixed coefficient valuation and original real target through fresh reification
and `CellQuote.finish`.

## Guards, refusals and proof evidence

[Guards](../conformance/HexRCF/CellReplay/Algebraic/Guards.lean) constructs −1
with supplied operations, proves its interpreted identity, and quotes the
source retaining 0 / (−1). The original divisor remains mandatory after the
zero numerator is normalized. A zero divisor fails before malformed decoding.

[Refusals](../conformance/HexRCF/CellReplay/Algebraic/Refusals.lean) includes
positive controls and checks exact refusal tags for a changed sample, an
unexpected left boundary, an absent right boundary, another point's valid
linear descriptor, a changed context and an empty literal inventory. It also
checks that a section row bound to the other conjugate is rejected, even when
the two rows have identical matrix signs. The
[mutation fixture](../conformance-fixtures/HexRCF/cell-algebraic-mutations.json)
and existing constructor renderer pin the specified field edits.

[Quoted](../conformance/HexRCF/CellReplay/Algebraic/Quoted.lean) rechecks the
actual two original-source proof bodies in a fresh module. It requires the
actual frozen readers, carrier acceptance and complete-root law, and excludes
the earlier source witness and scalar supplier. The source proofs have exactly
`propext`, `Classical.choice` and `Quot.sound`. Root-set and refusal theorems
are audited too. Active kernel reduction diagnostics separately prohibit native
root/sign/scalar production while accepting the packet and strict folds;
source dependency inventories alone do not establish that reduction property.

[Emit](../conformance/HexRCF/CellReplay/Algebraic/Emit.lean) reconstructs the
complete packet through the owners' codecs from the checked records. It uses
explicit supplied operations and emits ordinary stored data. The build enforces
exact byte equality with the owner writer's output for the original constructor
packet. Parsed emitted JSON also equals the frozen fixture. The writer emits
404,643 bytes; the compact fixture has 203,523 bytes.

## Validation scope

The existing optional default target, umbrella, conformance target and literal
renderer include the new modules. The manual has checked original-source,
root-set, strict-order and divisor examples. The existing rational cell
quotation and state-restoration controls remain required compatibility checks.
No tactic handler, approximation provider, family import in the base umbrella,
owner proof, publication wiring or CI job is added.

The packet inventories contain 34 explicit graph occurrences: 13 in the matrix
and 21 scalar graphs. They retain 75 nodes with multiplicity; unrolling repeated
binary child references visits 80 nodes. There are 32 distinct complete graph
literals. These counts exclude immutable context-frame graphs and internal
Sturm/Tarski records as additional occurrences. They are structural inventories,
not measurements of validation sharing, proof size or nested arithmetic cost.

Build records use an aggregate 32 GiB cgroup cap, no swap and two Lean worker
threads. They are correctness and operational resource records, not matched
AB/BA performance comparisons or degree/atom/precision/depth scaling evidence.
Shared constructor syntax does not imply shared validation across row readers.
The fixed packet establishes neither automatic certificate construction nor
acceptance completeness for every algebraic presentation.

binds the checked files to source commit `387922d3b0`, twelve successful
