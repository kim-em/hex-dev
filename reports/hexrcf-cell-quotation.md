# Pointwise cell quotation

`CellQuote.replayWith` quotes the exact supplied-operation checker in three
stages: its complete root reader, each dependent section/sector reader and the
strict Boolean/quantifier fold. Checked finite functions use every literal
index. `CellRead.collectWith_eq`, `CellOperations.readCells_of_parts` and
`check_of_parts` compose their equations at the original packet. All stages and
callbacks share one reflection budget; original divisor preflight and terminal
failures remain checked. No new tactic handler or arithmetic producer is added.

`RootQuote` now discovers proof dependencies in exposed helper bodies as well
as their types. Closed constructors containing replay-dependent proof fields
retain ordinary projection reductions consistently in reader terms, helper
types and helper bodies. A local constructor-type cache avoids repeatedly
scanning immutable metadata for the same protected boundary. Generated proofs
still undergo ordinary kernel checking against their exact original targets.

The constant controls use 502,481 nodes for true and 502,483 for false. They
check exact and one-node-below limits, wrong-goal proposals, malformed cells,
original zero-divisor preflight, terminal callback failures and full caller
restoration. The true result proves the original `∀ x : ℝ, 0 = 0`; the false
result cannot prove that source. These counts exclude source finishing.
