# Symbolic determinant diagnostic records

These retained observations attribute the successive proof-construction and
certificate changes. The stage JSON files contain the original compiler output,
CPU lease and environment record. Profiling instrumentation made those worktrees
dirty; these are diagnostic observations, not the clean six-pair shipping sweep
or crossover-fitting data. No instrumentation is part of the library sources.

`baseline`, `assembly`, `budget`, `tree`, and `kernel-forms` separate the requested
changes. The later `native-pack`, `typed-conjunction`, and `native-tree` records
measure their refinements. Every completed diagnostic is retained, including
slower observations. Repeated in-module kernel checks are order-sensitive and
are not independent fresh-module comparisons. `paired-certificate` and the
later paired records compare the old budgeted list-entry certificate with the
new tree-entry certificate; they are route comparisons on the same witness,
not identical propositions or a six-pair full-tactic performance claim.

The classification records and 248-observation partial forced run preserve
completed observations made before the proof-budget and crossover corrections.
They do not fit the final tables. The first full classification also contains a
missing-cache-artifact failure and two frontend timeouts during concurrent
build activity; their original output is retained. The final sweep runs after
its dependency build completes, with unchanged measured sources.

The output field `proof_node_budget` in these older diagnostics is an estimate,
not a measured proof size. `auxiliary nodes` reports the separate inspection.
The corrected implementation charges the shared compiled, capped counter on
the closed proof, including retained let-bound payloads. It counts distinct
nodes; the separate unshared `auxiliary nodes` metric remains the issue's
80,000-node attribution bar.

`capped-accounting` measures the retained implementation with capped distinct-node
accounting. `direct-tree` and `point-hint` retain experiments in direct quotation
and checked scalar-point hints. Neither established an improvement in the
component observations, and neither refinement is in the retained implementation.
The absolute entry-plus-target ceiling is not established by these diagnostics.

`dispatch-interrupted` retains the incomplete automatic comparison stopped after
the timeout-heavy schedule and session resource failure were reported. Its
completed pairs support only the explicitly preliminary table in the report;
they do not establish six-pair medians. `dispatch-user-interrupted` and
`dispatch-systemd-interrupted` retain the two earlier interrupted dispatch
attempts. They are not pooled with the reported pairs or used to replace samples.
