# HexInterval D2 representation and rational replay spike

## Accomplished

- Activated the Mathlib-free `HexInterval` library and moved its SPEC beside
  the source while leaving `HexIntervalMathlib` planned.
- Implemented exact open, closed, empty, and unbounded raw interval cuts,
  canonical normalization, proofs of consistency/idempotence, and a
  resource-safe `normalizeWithin` preflight for dyadic height and alignment
  shift.
- Compared proof-bundled and externally checked hot representations in
  compiled code and ordinary downstream kernel replay without selecting a
  public backing representation.
- Implemented and measured two Mathlib-free rational replay schemes: exposed
  wrappers around Core `Rat.normalize`, and signed numerator/denominator
  cross-product certificates with generic soundness for add, sub, mul, and
  inverse, including inverse at zero.
- Added conformance cases, CI-covered `decide +kernel` and
  `Lean.Kernel.whnf` canaries, the compiled spike driver, an interleaved
  measurement harness, a source-hashed JSON record, and the D2 findings report.
- Verified the complete `lake build` and all repository structure, benchmark
  dependency, conformance-target, copyright, and line-count checks.

## Current frontier

The raw cut and resource-preflight layer is usable, but the public interval
representation and trace encoding remain deliberately open. The current
experiment measures compiled newtype erasure and a validation scan; it does
not yet measure serialized proof-bearing interval literals against a reflected
trace.
