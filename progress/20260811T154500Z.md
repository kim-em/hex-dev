# Accomplished

- Added a generic proof-side refutation schema for an exact established fact.
- Added transparent contradiction elimination which produces an arbitrary
  branch target without consulting runtime contradiction state.
- Added the first real-domain adapter for the exponential fact lattice's
  `.empty` fact.
- Added an ordinary kernel theorem closing the target from exact bottom
  evidence and a reduction test rejecting the non-bottom `.all` fact.
