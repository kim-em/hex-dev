# Arbitrary-function semantic replay

## Accomplished

- Extended the cache-free semantic registry from fact-only coverage to exact,
  bidirectional package-owned coverage for fact, instantiation, and equality
  recipe formats.
- Gave instantiation recipes the conservative-extension obligation: every
  model of the old program extends to the appended program while agreeing on
  old nodes and preserving the operation table.
- Gave equality recipes an exact endpoint theorem under an explicit list of
  already-checked fact assumptions.
- Added public replay routes which follow the payload retained by a rule
  cause, instance event, or equality edge and reject a mismatched complete
  originating action before typed dispatch.
- Replayed the actual representation-free `sin (-x)` policy session through
  package-owned instance, equality, and contractor-fact schemas, without a
  central function language or rational backend.
- Added rejection canaries for mutated instance products, dynamic scopes,
  origins, bodies, equality endpoints, missing equality coverage, and
  transplanted entries.
- Updated the SPEC with the three semantic claims, exact coverage rule,
  origin-bound arena lookup, program-locality/chronology obligations, and the
  status of the arbitrary-function vertical.
- Built the complete 37-job interval conformance target set and reran DAG,
  copyright, source-line, diff-hygiene, and banned-proof-token checks.

## Current frontier

The live arbitrary-function session now reaches typed theorem dispatch for all
three package-produced proof roles. The remaining proof gap is the generic
chronological checker which validates program and fact histories, composes
rule entailment with fact-domain meet evidence, transports facts through
checked equalities, and closes the caller-selected target.

## Next step

Introduce a unified chronological replay cursor (or exact cross-history
cursors), add the semantic locality law needed to transport old facts across
program extensions, and implement the first forward checker over the retained
session trace.
