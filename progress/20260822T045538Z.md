# Hex characteristic polynomial implementation

## Accomplished

- Implemented the Mathlib-free Samuelson--Berkowitz characteristic-polynomial
  library, including Toeplitz multiplication, trailing-block recursion,
  coefficient/degree/monicity properties, trace, executable matrix evaluation,
  and the closed forms through dimension two.
- Implemented the Mathlib companion correspondence with `Matrix.charpoly`,
  Cayley--Hamilton, determinant/evaluation/trace transport, and transpose and
  similarity invariance, with no `sorry`, `axiom`, or `native_decide`.
- Added all specified conformance fixtures and guards, the exact JSONL snapshot,
  python-flint oracle support, random/structured/growth benchmark families, and
  persistent FLINT and PARI comparison paths.
- Integrated both libraries into Lake, the library DAG, the release manifest,
  the aggregate pins, documentation, and the existing single-job CI build,
  benchmark, and oracle sequences.
- Verified the full 9831-target default build, the conformance and fixture
  targets, exact fixture regeneration, all 17 FLINT oracle cases, all 13
  benchmark registrations including FLINT and PARI, and the DAG, release,
  trust-surface, copyright, line-count, and Mathlib-free-bench checks.
