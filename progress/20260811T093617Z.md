# Accomplished

- Added an authoritative chronological trace that interleaves expression instantiation, fact improvements, and retained equalities.
- Added replay checks for exact event order, equality ownership, write authority, final expression graph, and complete trace consumption.
- Fixed equality ownership so an instantiator cannot cite a fact that is only proved later in the trace.
- Added a transparent one-rule proof emitter which turns quoted plain data into an ordinary kernel-checked theorem without `native_decide`.
- Added a generic instance-reconstruction experiment that rebuilds expression-graph prefixes from declared node suffixes and a function-independent stability law, including zero-node events.
- Updated the SPEC to separate opaque search from trusted proof replay and to record the remaining multi-event proof-emission obligation.

# Current frontier

- The runtime checker validates complete multi-event traces, while transparent ordinary proof emission currently covers one rule event. The two paths intentionally do not pretend to be connected yet.
- The generic reconstruction experiment removes the need for a central function-specific instantiation callback, but is not yet integrated into the full trace checker.

# Next step

- Land this framework as a stacked draft PR, then add the separate real-sine vertical and extend transparent proof emission across instantiation, equality transport, and final target closure.

# Blockers

- A complete engine-generated theorem still requires a transparent multi-event replay fold or tactic-emitted applications of package-owned soundness lemmas.
