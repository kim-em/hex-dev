# Release-readiness implementation

## Accomplished

- Separated release-facing umbrellas from test and example modules, added the
  `HexReleaseTests` and `HexReleaseExamples` build roots, and taught the DAG
  checker about those explicit roots.
- Added executable integration examples for Releases 3, 4, and 5.  The Release
  4 example factors the degree-64 Swinnerton--Dyer polynomial and pins the
  public dispatcher trace to the lattice path; the Release 5 example exercises
  the total complex-root wrapper and repeated-real-root isolation.
- Added `HexRootsMathlib.isolate!` and its proof-facing equality, count, roots,
  and precision theorems, while keeping its selection/completeness semantics
  explicit in the documentation.
- Corrected the Release 3--5 dependency graph and claims, made release status
  include transitive dependencies and integration-example builds, and advanced
  only HexRoots and HexRealRoots through Phase 5 after their trust, build,
  conformance, and benchmark gates passed. HexBerlekamp remains at Phase 3
  because both of its gating FLINT comparator goals fail.
- Reconciled Berlekamp--Zassenhaus benchmark/API terminology and retained its
  unresolved performance verdicts as blockers.
- Made oracle execution fail closed in CI when FLINT, PARI, or Conway support
  is missing, while retaining explicit local skips.  Fixed the optional Conway
  mode and verified the full local optional suite.
- Expanded the release manifest to 33 split repositories plus the aggregate,
  including full transitive pins, managed test/bench/conformance assets, and
  standalone test-module declarations.  Added validation for manifest shape,
  paths, pins, topological order, README contracts, aggregate coverage, and
  test targets, and rewrote the bootstrap procedure around that manifest.
- Added a release trust-surface gate covering 168 Lean files and rejecting
  axioms, sorries, and `native_decide`.
- Added substantive READMEs for the 19 newly described split repositories,
  co-located the real-roots specifications, improved the root/factor tactic
  manual chapters, corrected stale testing and CI documentation, and shortened
  the encountered BHKS proof names.
- Verified a full `lake build` (9,449 jobs), release test/example/conformance/
  manual targets (9,475 jobs), manual rendering, all roots/real-roots/BZ smoke
  benchmarks, optional local oracles, the BZ trace gate, and every static gate.
  The final manifest, full published-source trust, DAG, Phase 4, and diff checks
  are green.

## Current frontier

- The implementation and release machinery are green, and each Release 3--5
  integration example builds.
- Formal readiness remains false.  Release 3/4 have 11 dependencies below
  Phase 7; Release 5 has five.  The newly advanced core libraries are at Phase
  5, while HexBerlekamp, their Mathlib bridges, and
  Berlekamp--Zassenhaus retain their honest lower counters.
- No released repository has been created, mutated, or synchronized during
  this session.

## Next step

- Complete the remaining independent phase audits in dependency order, with
  particular attention to the Mathlib bridge benchmark/report obligations.
- Close the HexBerlekamp Rabin and distinct-degree performance gaps before
  reclaiming its Phase 4 comparator gate.
- Re-run and reconcile the Berlekamp--Zassenhaus scientific benchmark report,
  resolve or explicitly disposition the fallback-probe regression and
  large-`r` scheduled evidence, then advance its phases only when their gates
  actually pass.
- Once all transitive libraries reach Phase 7, bootstrap any missing repository
  skeletons, run the release synchronizer in dry-run mode, inspect every
  generated split, and only then perform and verify a real publication sync.

## Blockers

- Berlekamp--Zassenhaus still has inconclusive scientific verdicts; its
  fallback probe is 7.07x slower than the Isabelle comparator at `n = 13`, and
  larger rungs hit the configured cap.  Large-`r` scheduled evidence is also
  incomplete.
- HexBerlekamp's gating FLINT goals fail at the largest eligible rungs: Rabin
  is approximately 1700x slower and distinct-degree factorization is
  approximately 2900x slower on the committed scientific evidence.
- Several bridge libraries have not completed their required documentation,
  benchmark, performance-report, and final release-review phases.
- This environment does not have the optional FLINT/PARI Python packages, so
  the CI-required oracle mode was not reproduced locally.  CI installs and now
  requires them; local optional mode passed with explicit skips and the Conway
  cache check passed 36/36 comparisons.
- Publishing requires external repository/bootstrap authority and an inspected
  dry run; neither was implied by the implementation request, so no external
  repositories were changed.
