# Version-zero initial-target evidence

## Accomplished

- Added `Proof.initialTarget`, which derives entailment from an exact index and
  exact target node/fact equalities against `initialBase` without executing a
  program or invoking a runtime theorem schema.
- Added `RuntimeEmit.Checked.emitInitialTargetWithin` for the sole root target
  at program/fact version zero with an empty chronology and no seeded edge.
  It quotes the ordinary checked input, kernel-checks reflexive node and opaque
  fact correlations, and emits the exact correlated Evidence term.
- Preserved limit parity: the fast path rebuilds the proof registry under the
  caller's `Proof.Limits`, retains emitter schema and two-stage expression
  caps, and consumes only a `Checked` token already admitted by result and
  proof-tree limits.
- Added focused conformance using the ordinary checked interval quoter. It
  pins the opaque `getValue (ofRawWithin ...)` fact representation, exact
  version/chronology refusal, minimal singleton depth, result/proof node and
  edge-inclusive work refusals, registry/schema/expression one-under limits,
  and rollback after failed emission.
- Updated the Mathlib interval SPEC with the theorem boundary and exact limit
  phase ownership.
