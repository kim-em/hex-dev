# issue-9151: prepared lift modulus in the recombination trailing filter

## Accomplished

- Added `Hex.LiftModulus` (natural value, integer value, halfway threshold,
  plus the two proof fields pinning the derived values) and
  `Hex.LiftModulus.centered`, with `Hex.LiftModulus.centered_eq` proving it
  equals `Hex.centeredModNat`.
- `Hex.SupportMeta` now carries one prepared modulus in place of its former
  `modulus : Nat` / `modulusInt : Int` pair;
  `Hex.SupportMeta.modulusNat_spec` and `modulusInt_spec` recover both views.
- `Hex.directTrailingPrefilter`, `Hex.directCandidatePrefilter`,
  `Hex.tryDirectCandidate` and `Hex.directLeaf` consume the prepared modulus.
  `Hex.directTrailingPrefilter_eq` states the production filter returns the old
  Boolean. The classical completeness proofs carry the prepared modulus and
  prove the same conclusions.
- Wrote `reports/hexbz-prepared-lift-modulus.md` with the leaf-loop cost
  analysis, the generated-C evidence, and the measurement tables.

## Findings worth carrying forward

- `Int.ofNat` is `@[extern "lean_nat_to_int"]`, and `lean_nat_to_int` returns a
  non-scalar argument unchanged: `Nat` and `Int` share the GMP-backed object
  representation. Converting a multi-limb `Nat` modulus to `Int` costs a
  reference-count increment, not a limb copy. The real per-leaf allocation was
  `2 * r.natAbs` in `centeredModNat`'s halfway comparison, which the prepared
  threshold removes.
- `sd5` no longer recombines. Since #9181 it answers through
  `method=quadraticNorm` with `candidatesTried = 0`, and its production profile
  is prime planning and Berlekamp, not the leaf loop. The 18.26% / 10.44%
  shares the issue quotes came from a profile at `bf5973a3`. Any future issue
  that prices a recombination change against `sd5`'s production time is
  measuring a path the cascade no longer takes; use `sd5_x_phi11`,
  `sd4_x_sd4shift1`, or the phase profiler's forced classical decomposition.

## Current frontier

Measurements: recombination phase improves 4.5% to 13% on the rows the
trailing filter dominates, flat where candidate construction dominates
(`xpow120_minus1`), controls unchanged.
