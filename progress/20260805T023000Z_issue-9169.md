# Primitive element and minimal polynomial of a multiquadratic sum (#9169)

## Accomplished

`HexBerlekampZassenhausMathlib/Multiquadratic.lean` (new, wired into
`HexBerlekampZassenhausMathlib.All`) carries parts (2) and (3) of the tower
theorem from `reports/hexbz-quadratic-norm-certificate.md`, on top of #9167's
`SquareClass.lean`:

- `finiteDimensional_adjoinSqrt`, `normal_adjoinSqrt`, `isGalois_adjoinSqrt`.
  Normality is by list induction: `adjoinSqrt (d :: ds) = adjoinSqrt ds ⊔ ℚ⟮r⟯`
  and each `ℚ⟮r⟯` is the splitting field of `X² - d`, so `normal_sup` applies.
  Separability is characteristic zero.
- `signSum c r ε = c + ∑ᵢ ± rᵢ` and `signPoly c r = ∏_ε (X - signSum c r ε)`,
  both over an arbitrary ring so the tower and `ℂ` share one definition, with
  the ring-map transport lemmas `map_signSum` and `map_signPoly`.
- `eq_zero_of_sum_eq_zero`: no nontrivial *integer linear relation* holds among
  the chosen roots. This is the one place independence is used at an arbitrary
  index; the index is moved to the front with `List.eraseIdx` and
  `sqrt_notMem_adjoinSqrt`.
- `eq_one_of_gen_fixed`: trivial stabilizer. `adjoin_gen_eq_top` and
  `adjoin_signSum_eq`: `ℚ(α) = K`.
- `signOf_bijective`: `σ ↦ (εᵢ(σ))` is a bijection onto `Fin n → Bool`.
- `minpoly_map_eq_signPoly`, `natDegree_minpoly_signSum`,
  `irreducible_of_map_eq_signPoly` (over `ℚ`) and
  `irreducible_int_of_map_eq_signPoly` (over `ℤ`, by Gauss).
- `signSum_injective`: the `2ⁿ` sign sums are pairwise distinct.

Zero `sorry`/`axiom`/`native_decide`; `#print axioms` on the headline theorems
reports only `propext, Classical.choice, Quot.sound`.
`lake exe runLinter HexBerlekampZassenhausMathlib.Multiquadratic` passes.

## Decisions

**The `2ⁿ` conjugates are never constructed.** The issue's decomposition
routes the minimal polynomial through surjectivity of `σ ↦ (εᵢ(σ))` and an
orbit-cardinality count. That is not needed: an automorphism is only ever
*read* (`σ(rᵢ)² = rᵢ²` forces `σ(rᵢ) = ± rᵢ`), never built. Each `σ` permutes
the sign patterns by exclusive-or with its own, so `signPoly` is fixed by all
of `Gal(K/ℚ)`, hence has rational coefficients; it is monic of degree `2ⁿ` and
vanishes at `α`, and `[ℚ(α) : ℚ] = 2ⁿ` from the Galois correspondence, so it
*is* the minimal polynomial. `signOf_bijective` is still proved, because the
issue asks for it, but nothing downstream of it is used.

**Distinctness is not a separate argument**, as the issue warns. Both it and
the trivial stabilizer are instances of `eq_zero_of_sum_eq_zero`, which is
stated with arbitrary integer coefficients precisely so it covers both: the
stabilizer case has coefficients in `{0, -2}`, the distinctness case in
`{0, ±2}`.

**The consumable irreducibility statement takes the polynomial as input.**
`Irreducible (minpoly ℚ α)` is trivially true and useless. What a checker needs
is: *if* `f` maps to the sign-pattern product, *then* `f` is irreducible. That
is `irreducible_of_map_eq_signPoly`, and it needs no monicity hypothesis over
`ℚ` because `Polynomial.map` along `algebraMap ℚ ℂ` is injective.

## Gotcha: two `Algebra ℚ ↥K` instances

`Algebra ℚ ↥(adjoinSqrt ds)` synthesizes to `DivisionRing.toRatAlgebra`, not to
`IntermediateField.algebra'`. The two are definitionally equal, but not at the
reducible transparency instance synthesis and `rw` use. Consequences:

- `infer_instance` cannot see an `ih : Normal ℚ ↥(adjoinSqrt ds)` when the goal
  came from `IntermediateField.normal_sup`; the instance argument has to be
  passed with `@`.
- `rw [IntermediateField.mem_map]` and `rw [IntermediateField.adjoin_map]` fail
  on goals mentioning `N.map (adjoinSqrt ds).val`. Term-mode
  `(IntermediateField.mem_map _).1` still works, and `adjoin_signSum_eq` is
  proved by `eq_of_le_of_finrank_eq` instead of by transporting
  `adjoin_gen_eq_top` along `.map`, which avoids the issue entirely.

Anything that has to state a fact about `IntermediateField ℚ ↥(adjoinSqrt ds)`
should expect this.

## Current frontier

#9168 landed as #9175 while this was in progress, so both halves of the
certificate's soundness now exist -- but against two different encodings of the
same polynomial. `HexBerlekampZassenhausMathlib.signPatternPoly` is a
`List.prod` over a fold-built list of signed sums; `Hex.SquareClass.signPoly` is
a `Finset.prod` over `Fin n → Bool`. The `Fin n → Bool` indexing is not
incidental: an automorphism acts on the product by reindexing along an
involution of the pattern type, which is the whole argument for the coefficients
being rational.

So the composition needs one more lemma,

    signPatternPoly (c : ℂ) rs = signPoly c (fun i => rs[i])

for `rs` of length `n`. It is a multiset identification between the fold and the
function space, provable by induction with `Fin.snoc`, and it is the last thing
between `Hex.QuadraticNormCertificate.check f = true` and `Irreducible f`.
Deliberately not done here: #9169 scopes the identification of the sign-pattern
product with anything executable out, and this belongs with #9170's integration.
