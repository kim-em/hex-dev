# Arbitrary-function chronological replay

## Accomplished

- Added package-independent chronological composition for rule events:
  resolved input facts, the previous target fact, the package theorem, and the
  fact-domain meet theorem now produce a theorem for the installed fact.
- Added a private forward fact prefix which exposes caller seeds only at
  version zero, appends only successfully replayed positive versions, and
  rejects duplicate or future references.
- Added equality transport through package-owned equality theorems, with exact
  endpoint orientation and same-domain checks before semantic transport.
- Added package-owned instance replay and semantic program extension
  composition.
- Added explicit semantic stability evidence for append-only program steps,
  including model restriction and fact locality across agreeing old/new node
  values.
- Added fact-prefix lifting across an instance step. Old facts retain proofs;
  only genuinely appended nodes receive proved version-zero top facts.
- Added a private cursor indexed by the exact program version and program.
  Instance replay checks the cursor-relative origin/version and exact appended
  node suffix; rule replay checks the exact current version.
- Drove the actual representation-free arbitrary-function session from its
  original graph through expression instantiation, fact-prefix lifting, new
  top facts, and invocation of the dynamically installed propagator.
- Added rejection canaries for future fact references, duplicate events,
  stale cursor versions, mutated fresh-node lists, malformed meets, reordered
  inputs, wrong equality sources, and mixed-domain equality transport.
- Updated the SPEC with the implemented proof boundaries and remaining
  full-history ordering question.
- Built the 39-job interval conformance target set and passed DAG, copyright,
  source-line, diff-hygiene, and banned-proof-token checks.

## Current frontier

The generic checker can now follow one actual package-owned instantiation and
the arbitrary propagator it installs without knowing the function or using a
rational backend. It owns the current program and proved fact history rather
than consulting final mutable engine state.
