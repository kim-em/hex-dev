# 2026-09-05 feature session: issue #9992, kernel-friendly certificate checker

Accomplished:
- `scripts/bench/graphiso_kernel_cost.py`: profiles every negative corpus pair,
  reports kernel time per certificate record and its exponent in `n`; a
  `graph_iso` trace class reports route and record counts. Baseline and final
  records under `reports/bench-results/hexgraphiso-kernel-*.json`.
- `HexGraphIso/Nauty/Packed.lean`: fixed-width fields packed into one `Nat`
  (`pack`/`pget`/`pset`, `Rep` correspondence), raw kernel-accelerated
  spellings of the bit-set operations, byte-table `popCount`/`lowBit`, the
  `Nat.rec` loop drivers `iterUp`/`fuelRec`.
- `HexGraphIso/NodePacked.lean`: the certificate replay over packed state,
  each clone proven equal to the list clone; `checkKeyP` over the rows tied as
  one packed number; `not_isomorphic_of_checkKeysP`.
- `HexGraphIso/SeparatorPacked.lean`: the root and two-code separators over
  packed state.
- Tactic emits the packed obligations; `precompileModules` on `HexGraphIso`;
  the timing scripts use `lake lean` so the precompiled search is loaded.

Measured (chungus2): kernel time on the cycle ladder and Kneser pair down 3.4
to 5x, per-record exponent 1.80 to 1.47 at n <= 21; the 48- and 61-vertex
timeouts now close in 65 s and 54 s; interpretation share gone. The 96-vertex
pair still exceeds the budget (377 s kernel with `maxRecDepth` raised).

Decisions: certificate-carried split sequences examined and not adopted
(see reports/hex-graph-iso-performance.md). The released mirror's
`lakefile.toml` does not yet carry `precompileModules = true`; the manifest
flag was left off so the sync keeps working, follow up when the mirror is
touched.

Remaining: cactus sweep regeneration was run at the end of this session (see
the PR); further kernel gains would come from fewer accelerated operations per
refinement pass (the neighbour counts dominate) and from the families' own
adjacency evaluation, which is the floor.
