# Accomplished

- Revalidated every installed package-owned scope, as well as every proposed
  scope, against the prospective final program at reply retention, policy-key
  refresh, and final admission.  A program extension now rolls back if it
  would invalidate an existing package binding contract.
- Made the policy's remaining-generation view derive from committed instance
  events, so scope-only and equality-only instantiations consume the same
  theorem-generation budget as node-producing events.
- Corrected the watcher-order contract from prefix stability to old-entry
  subsequence stability and added a mixed equality/dynamic-application canary
  which distinguishes the two.
- Cached validated application and proposal semantic-item counts.  Policy view
  preflight can now reject a small traversal allowance without walking large
  port lists, while complete views charge the exact logical key surface.
- Added exact traversal canaries and updated the maintained-frontier workload
  envelope without changing its deterministic work totals.
- Rebuilt the complete affected experiment and conformance rollup.
