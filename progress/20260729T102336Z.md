# Accomplished

- Replaced the standalone matcher’s scheduler dependency with a generic
  append-stable structural cursor module.
- Added registration-wide whole-network matcher applications.  Exactly one
  global application is compiled per matcher registration, including when
  later instantiation creates additional nodes with the matcher’s head.
- Put matcher cursors, prepared progress, visit limits, and visit accounting
  inside the engine.  Function packages receive only bounded structural
  batches; cursor progress commits only after a valid reply.
- Threaded the same prepared batch through FIFO scheduling, package-registry
  dispatch, policy offer identity, policy selection, reply observations,
  retries, and engine budget views.
- Made node, equality, and application match generations causal inputs to
  instantiation generation and instance deduplication.
- Added end-to-end conformance for a global sine-shape matcher which creates
  `sin x`, `-(sin x)`, an equality, and an arbitrary-scope contractor, then
  renews over the exact appended delta.  A second proposal triggered by an
  equality/application batch is stamped generation two.
- Added canaries for poll/reply cursor atomicity, partial batches, matcher
  resource visibility, package dispatch, and policy selection.
- Built the 26-job interval target set successfully.
