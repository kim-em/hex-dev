# Accomplished

Added the first supported public interval operations on top of the sealed
bundled representation. `intersectWithin` preflights both same-side endpoint
comparisons and sends the selected cuts through the checked canonical boundary;
`negWithin` swaps and negates cuts through that same boundary. Resource refusal
remains distinct from canonical empty. Computational conformance pins strict
tied cuts in both openness positions, unbounded inputs and negation, empty
laws, and refusal before a billion-bit dyadic alignment.

Activated the public `HexIntervalMathlib` companion. Its independent real-cut
semantics proves that every successful intersection is exactly conjunction and
that successful negation contains `x` exactly when the input contains `-x`.
The proof does not import the experimental propagation fact domain. Registered
the conformance theorem and guarded its ordinary-kernel axiom surface.

# Current frontier

The public API now covers canonical construction, exact intersection, and
negation. The Mathlib companion is both a Lake default target and an explicit
cached CI library target. Hull and arithmetic images remain experimental. The
operation names retain `Within` because public values do not store the endpoint
budget under which they were constructed.
