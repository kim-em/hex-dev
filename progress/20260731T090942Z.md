# Release cleanup checkpoint

## Accomplished

- Restored the advertised root `Hex.ZPoly` irreducibility API and added a
  release regression module that imports the ordinary umbrella and checks the
  public names and decidable instance.
- Moved the seven internal monic-lift facts out of the accidentally nested
  namespace and into the mathematical `MonicLift` namespace.
- Removed `HexLLL.Basic`, the total `choosePrimeData` wrapper, the unused-monic
  representation theorem, the two ordinary-selector compatibility wrappers,
  and `DensePoly.coeff_ofCoeffs_list`.
- Migrated coefficient-list specifications to `DensePoly.ofList` while keeping
  their array implementations and compiled equality theorems.
- Replaced the generic release-chain module names with mathematical names:
  Berlekamp matrices, polynomial equivalences, modular polynomials, coprime
  lifts, Hensel lemmas, external reduction, integer lattices, square-free
  inputs, factorization data/results, and the classical, trial, quadratic, and
  recombination factorization modules.
- Renamed `CoreProblem` to `SquareFreeInput` and removed the empty
  `FactorEntryPoints` import shim.
- Removed every `maxHeartbeats` override from the release chain, including the
  duplicated nested commands and file-wide settings in the reduction-modulo-p
  proofs; all affected modules compile with Lean's ordinary budget.
- Split the public LLL reduction theory from its internal reduction invariant,
  and split the lattice factorization proof into projected-row, cut-projection,
  and support-equivalence modules.
- Split the local-factor theory into lifted integral factors, modular factor
  products, and modular factor coprimality.
- Replaced the remaining provider/reifier/elaborator module labels with
  polynomial-tactic, factor-tactic, certificate-syntax, and kernel-factor
  modules.
- Put the longest imported trial, recombination-search, and Mahler-measure
  theorems in mathematical namespaces with short result names.
- Curated both ordinary Berlekamp-Zassenhaus umbrellas to their supported
  factorization, soundness, and tactic surfaces, with explicit `All`
  development umbrellas for the complete module collections.
- Replaced the tactic registration API's software-oriented provider and
  dispatch names with `Extension`, `ExtensionResult`, and `applyExtensions`.
- Renamed the factorization trace classification from `FactorTier` to
  `FactorMethod`, including the committed conformance schema and deterministic
  trace baseline.
- Renamed the direct-coordinate lift API from `coreLiftData` to
  `directLiftData`.
- Recast optional LLL acceleration as a certified external reduction:
  `loadExternalReducer`, `externalReduce`, and `certifiedReduction`.
- Renamed the remaining generic release-chain modules to mathematical objects,
  including residue arithmetic, the `ZMod64` ring equivalence, polynomial
  quotients, factor irreducibility, the Eisenstein criterion, and lattice
  factorization.
- Added dedicated manual chapters for finite-field Berlekamp factorization and
  integer Berlekamp-Zassenhaus factorization; shortened every released README
  to the required section order and checked all thirteen first quickstarts.
- Documented the supported declarations, constructors, record fields, and
  cross-module theorems throughout the release chain, and removed historical
  and software-engineering terminology from its public prose.
- Rebuilt the manual, tactic regressions, factorization libraries, conformance
  library, fixture emitters, benchmark executables, and native LLL executable
  after the settled renames.
- Declared the two development `All` umbrellas as explicit release-test build
  roots, preserving the smaller public umbrellas while satisfying the DAG
  completeness check.
- Rebuilt the complete monorepo successfully: 9,704 jobs on Lean 4.32.2.
