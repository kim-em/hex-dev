# Evaluator-proof memoization

## Accomplished

- Reworked `Hex.Interval.Tactic.evalProof` around a traversal-local functional
  cache of exact reified terms, their correlated Lean expressions, and fully
  checked proof expressions.
- Reused proof expressions only after checking the cached expression is
  syntactically identical and replaying `Proof.emitChecked` against the freshly
  reconstructed expected equality.
- Kept the public `evalProof` signature unchanged and quoted the source-value
  function and runtime rule configuration once per top-level traversal.
- Documented the existing repeated-reciprocal conformance theorem as the
  representative shared-subterm cache-hit canary.
- Built `HexIntervalMathlib.Tactic` and
  `HexIntervalMathlib.TacticConformance`; ran DAG, trust-surface, forbidden-term,
  and whitespace checks successfully. A matching-manifest prebuilt package
  tree was reused to avoid a cold Mathlib build.

## Current frontier

The focused implementation and conformance target are green. The cache is
private, immutable across recursive calls, bounded by the already bounded
reified term graph on the public tactic path, and never stored in Meta state or
across top-level tactic invocations.
